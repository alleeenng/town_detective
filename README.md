# README — Детективная игра «Ограбление ювелирного магазина»

Консольная текстовая игра на Python. Вы — детектив, расследующий ночное ограбление ювелирного магазина. Цель: собрать минимум **3 улики** и обвинить преступника.

## Запуск

```bash
python main.py
```

Требуется Python 3.x, без сторонних библиотек.

## Подозреваемые

`petrov`, `ivanov`, `kuznetsova`, `chernov`

## Команды

| Команда | Действие |
|---|---|
| `help` | Список команд |
| `look` | Осмотреть локацию |
| `go` | Перейти на локацию (`flat`, `street`, `cafe`, `office`, `police`, `warehouse`) |
| `take` | Подобрать улику |
| `talk <name>` | Поговорить с подозреваемым |
| `accuse <name>` | Обвинить подозреваемого |
| `exit` | Выйти из игры |

## Условия

- **Победа:** `accuse ivanov` при ≥ 3 уликах.
- **Поражение:** обвинение другого подозреваемого или `ivanov` с < 3 уликами.

Всего в игре 4 улики (на локациях `street`, `cafe`, `warehouse`, `police`).
